# SaaS branding and tenant identifiers

- OpenChat is the IM application brand.
- SaaS is the platform/tenant application; tenant-facing status and wallet copy uses
  `SaaS 币`, not `OpenChat币`.
- Demo tenant code: `saas-demo`.
- Demo tenant name: `SaaS 生活服务`.
- Demo hotel: `SaaS Hotel`.
- Tenant administrator: `tenant-admin` (display `租户管理员`).
- C 端 entry: `/c/`; B 端 entry: `/b/`; admin entry: `/saas/`.
- Legacy `A380` tenant code, hotel name and `/a380/` path are not registered.
