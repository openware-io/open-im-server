# SaaS branding in local/Ack manifests

- OpenChat is the IM application brand; SaaS is the platform/tenant product.
- Demo SaaS tenant: `saas-demo` / `SaaS 生活服务`.
- Demo SaaS hotel: `SaaS Hotel`.
- Tenant administrator: `tenant-admin` / `租户管理员`.
- Wallet display brand: `SaaS 币`.
- C 端 is `/c/`, B 端 is `/b/`, admin is `/saas/`.
- `/a380/` and the legacy A380 tenant data are not valid deployment targets.
