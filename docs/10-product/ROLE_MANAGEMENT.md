# 角色与权限页面（产品说明）

[English](ROLE_MANAGEMENT.en.md)

> 状态：`current`（2026-10-29）
> 页面：平台运营后台 → 权限管理 → 角色与权限；租户后台 → 人员与权限 → 角色与权限

## 1. 页面定位

角色与权限页面用于查看、创建和维护平台/租户/门店角色：

- 平台角色：平台级角色，按 PLATFORM 可授予范围配置权限；
- 租户角色：租户级角色，可创建 TENANT/STORE 角色；
- 门店角色：租户内门店范围角色；
- 预置角色只读，需要调整时复制为自定义角色。

权限目录矩阵是只读对照视图，本页是授权编辑入口。

## 2. 入口与菜单

| 后台 | 菜单路径 | 可见条件 |
| --- | --- | --- |
| 平台 | 权限管理 → 角色与权限 | 平台 AdminRole（SUPER_ADMIN / PLATFORM_ADMIN） |
| 平台 | 权限管理 → 权限目录 | 平台 AdminRole（SUPER_ADMIN / PLATFORM_ADMIN） |
| 租户 | 人员与权限 → 角色与权限 | `iam.role.view`（写操作另需 `iam.role.manage`） |

菜单不可见时直接访问页面仍会被服务端拒绝（403）。

## 3. 角色列表

- 显示角色名称、编码、类型、作用域、权限数量；
- 权限数量由批量接口一次加载；
- “权限矩阵”打开单个角色的权限编辑弹窗；
- 只有 `iam.role.view` 的账号可查看角色与权限矩阵，但不可新建、复制、保存或分配人员；
- “复制”基于现有角色创建新角色（需 `iam.role.manage`）；
- 平台额外提供“工作台默认值”“查看权限目录”；
- 租户额外提供“分配人员”。

## 4. 权限矩阵编辑

- 只展示当前角色作用域可授予的权限；
- 预置角色只读；
- 只有查看权限时权限矩阵为只读，底部不显示“保存权限”；
- 保存时带版本；如果其他管理员已修改同一角色，提示冲突并重新加载最新授权；
- 关闭未保存修改会二次确认；
- 平台角色可配置 PLATFORM 可授予的经营权限，平台运营进入租户上下文时使用同一权限快照。

## 5. 数据刷新

- 页面提供“刷新”；
- 从其他页面/窗口返回、页面重新可见时会静默刷新（弹窗打开时不打断编辑）；
- 打开单个角色权限矩阵前会重新拉取权限元数据，确保 `grantable_levels` 是最新的；
- 权限数量、角色目录和权限编辑器使用同一上下文，不跨租户复用。

## 6. 常见问题

**Q：为什么租户后台看不到“角色与权限”？**  
A：需要当前账号具备 `iam.role.view`；菜单由后端按权限下发。

**Q：为什么只能看、不能改？**
A：查看权限是 `iam.role.view`，新建/复制/保存/分配人员需要 `iam.role.manage`。

**Q：为什么预置角色不能直接改权限？**  
A：预置角色是系统基线，只读；请使用“复制”创建自定义角色后调整。

**Q：保存时提示“权限已被其他管理员修改”怎么办？**  
A：系统已重新加载最新授权；确认差异后再次保存即可。

**Q：为什么角色页面的权限数量和权限目录矩阵不一致？**  
A：两者分别按角色/矩阵维度展示；角色页刷新后会与当前 IAM 数据一致。如仍不一致，请检查是否有未刷新的页面或权限版本冲突。

## 7. 验收标准

- 平台/租户有权限的用户能从菜单进入角色页；
- 无 `iam.role.view` 的用户看不到菜单，直接访问接口返回 403；
- 只有查看权限的账号打开权限矩阵为只读，不能保存/分配人员；
- 租户角色页不显示“工作台默认值”；
- 平台角色页可从菜单进入“权限目录”；
- 权限数量为批量加载，页面刷新/重新聚焦后更新；
- 打开权限矩阵时使用最新权限元数据；
- 预置角色只读，保存冲突有提示。
