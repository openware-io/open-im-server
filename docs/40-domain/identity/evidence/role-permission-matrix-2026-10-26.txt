Issues found and fixed during this test:
  1. Tenant account could call /api/v1/admin/platform/tenants and got 200.
     Fixed gateway: platform routes only forward platform-scope token.
     Fixed tenant controller: require Platform scope; tenant -> 403.
  2. Platform route was still reachable in UI for tenant accounts.
     Fixed router guard: non-PLATFORM workspaces redirect to their workspace.
  3. store.manager role profile landed on /admin/tenant/overview (HQ only).
     Fixed role profile landing to /store; added migration V19.
  4. B admin customer list failed with CLIENT_AUDIENCE_FORBIDDEN because context
     token clientApp=saas-b but customer service allowed only saas-c.
     Fixed customer audience to allow saas-c + saas-b (B backend) + saas-admin.
  5. One legacy plaintext PII row made the whole customer list 500.
     Fixed per-field decryption fallback; bad cipher logs WARN and renders empty,
     not a page-level 500.
